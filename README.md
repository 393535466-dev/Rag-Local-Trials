# 知序 · 企业知识库中台

当前阶段：前端交互原型 + 零依赖本地模拟 RAG 后端。后端已跑通“解析/OCR 适配 → 分块 → Embedding → 召回 → Rerank → 模拟 LLM → 引用/用量/日志”链路；真实百炼和外部模型尚未连接。

## 预览

在本目录执行：

```bash
npm install
npm run dev
```

然后打开终端显示的本地地址，默认是 `http://127.0.0.1:5173/`。执行 `npm run build` 可检查 TypeScript 并生成静态构建。

## 建议评审路径

1. 以“管理员”查看模型配置。OpenRouter、AIHubMix、通义百炼分别提供 LLM、Embedding、Rerank 的模型 ID 输入；百炼额外展示文档解析配置。请只输入示例值，勿在原型中填写真实密钥。
2. 切换“知识库管理人员”，创建知识库，进入详情，查看上传、解析状态、文档预览与检索测试。
3. 切换“使用者”，选择知识库并发起对话，点击示例回答中的来源引用。
4. 切回“管理员”，查看运行日志中的查询内容、Tokens、耗时和失败状态。

未启动后端时，文件选择会退回到前端演示模式，只读取文件名与大小；启动本地模拟后端后，文件会通过 `multipart/form-data` 上传，并经历“排队中 → 解析中 → 可检索”状态。示例回答、引用、检索结果和统计数据仍不代表真实模型调用。模拟后端默认将文件、知识片段和日志保存到本地 `data/` 目录，重启服务后会自动恢复。

已确认的开发方案见[方案草案.md](./方案草案.md)。当前后端已经具备模拟百炼 RAG 的最小编排能力，下一步再将前端检索测试和在线对话页面接到这些 API。

## 本地模拟后端

如需验证真实文件上传和异步解析状态，可在另一个终端启动：

```bash
python3 backend/server.py
```

服务默认地址为 `http://127.0.0.1:8000`。启动后刷新前端页面，右上角会显示“本地模拟后端已连接”。接口说明、`curl` 示例和状态字段见 [backend/README.md](./backend/README.md)。本地数据位于 `data/rag.sqlite3` 和 `data/uploads/`，已加入 `.gitignore`，不会推送到 GitHub。
